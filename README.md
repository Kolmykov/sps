# SPS Group — сайт (рабочий макет)

Одна страница: `index.html`, картинки в `img/`. Открыть `index.html` в браузере, сборка не нужна.

- Только десктоп (1440 и 1920).
- Люди на фото сгенерированы и будут заменены фотографиями сотрудников SPS.
- Формы проверяют телефон и показывают состояние «принято», данные никуда не уходят.
